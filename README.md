# DocFiller

Локальное приложение для генерации договоров по шаблонам `.docx` с данными людей из локального Excel-файла. Без базы данных.

## Скачать

Готовый установщик для Windows: **[DocFiller-1.0.0.msi](https://github.com/GarnetAki/docfiller/releases/latest/download/DocFiller-1.0.0.msi)** (раздел [Releases](https://github.com/GarnetAki/docfiller/releases)). JDK ставить не нужно — всё включено.

## Запуск из исходников

Нужен JDK 21 (JAVA_HOME должен на него указывать). Из папки проекта:

```
gradlew.bat run
```

Сборка установщика Windows (msi): `gradlew.bat packageMsi` — результат в `build/compose/binaries/`.

## Как пользоваться

1. **Люди** — в файле `data/people.xlsx` (создаётся при первом запуске с примером).
   Первая строка — названия колонок. Колонки `ID` и `Теги` служебные, их приложение
   заполняет само; остальные колонки добавляйте и заполняйте в Excel как угодно.
   После правки файла в Excel нажмите «Обновить» в приложении (файл при этом должен
   быть закрыт в Excel, иначе Windows не даст его перезаписать).
2. **Теги** — кнопка «Теги…»: слева список тегов (создание, удаление), справа —
   галочки принадлежности людей к выбранному тегу. Фильтр списка людей по тегу —
   выпадающий список «Все теги».
3. **Генерация** — выберите шаблон из папки `templates/`, отметьте людей,
   заполните поля события, укажите начальный номер договора и папку сохранения.
   На каждого человека создаётся отдельный файл, номер договора увеличивается на 1.
   Если у человека не заполнено нужное поле — в конце покажется предупреждение,
   а в документе на этом месте будет короткая линия `__________` (её можно
   заполнить от руки или найти поиском по подчёркиваниям).

## Разметка шаблонов

Шаблон — обычный `.docx` в папке `templates/`, где на месте подставляемых значений
стоят плейсхолдеры:

| Плейсхолдер | Значение |
|---|---|
| `{{contract.number}}` | Номер договора: начальный номер + порядковый индекс человека. Суффикс пишется текстом: `№ {{contract.number}}-СЗ` |
| `{{event.имя_поля}}` | Поле события — приложение покажет текстовое поле в форме генерации |
| `{{person.Имя колонки}}` | Значение из одноимённой колонки `people.xlsx` |
| `{{each.Имя поля}}` | Значение вводится при генерации отдельно для каждого человека: после нажатия «Сгенерировать» появляется окно со списком выбранных людей и полем ввода у каждого (предзаполняется из одноимённой колонки Excel). Пример: `{{each.Сумма}}` |

Модификаторы (через `:`):

- `{{each.Сумма:прописью}}` — число прописью: `10 800` → «Десять тысяч восемьсот»
- `{{person.ФИО:инициалы}}` — «Иванов Иван Иванович» → «И.И. Иванов»

Готовый пример — `templates/Договор СЗ.docx` (договор + акт).

Важно: плейсхолдер должен быть внутри одного абзаца (Word иногда «разрезает»
текст при редактировании — приложение такие случаи обрабатывает, но лучше
вписывать плейсхолдер целиком). Если плейсхолдер не заменился — проверьте,
что в документе нет лишних пробелов внутри `{{ }}` (допускаются) и что
название колонки совпадает с заголовком в Excel (регистр не важен).

## Сбор данных от людей через онлайн-форму

Люди могут сами заполнить свои данные через Яндекс Форму или Google Форму,
а вы импортируете ответы в приложение кнопкой «Импорт…» (вставка из буфера
обмена или файл .xlsx/.csv).

1. Создайте форму с вопросами, названия которых совпадают с колонками
   `people.xlsx` (регистр не важен). Минимальный список:
   - ФИО
   - Дата рождения
   - ИНН
   - СНИЛС
   - Паспорт серия
   - Паспорт номер
   - Паспорт дата выдачи
   - Паспорт кем выдан
   - Код подразделения
   - Адрес регистрации
   - Банк
   - БИК
   - К/С
   - Л/С
2. Для Google Формы: «Ответы» → «Связать с таблицей». Для Яндекс Формы:
   скачайте ответы в XLSX.
3. Откройте таблицу ответов, скопируйте строки вместе с заголовками
   (Ctrl+A, Ctrl+C) и в приложении нажмите «Импорт…» → «Вставить из буфера»
   — или просто выберите скачанный файл.
4. Приложение покажет, какие колонки сопоставлены, какие будут созданы новые.
   По умолчанию строки с уже известным ФИО **обновляют** существующего человека
   (пустые ответы не затирают заполненные поля), новые ФИО добавляются.

При импорте значения приводятся к единому виду (уже правильные не меняются):

- **СНИЛС** — из цифр: `12345678901` → `123-456-789 01`
- **Паспорт серия** — `7010` → `70 10`
- **Код подразделения** — `720003` → `720-003`
- **Даты** (дата рождения, дата выдачи паспорта) — `2014-07-06`, `30/06/2020` → `30.06.2020`

Если цифр в значении не хватает или дата не распознана — значение сохраняется как есть.

## Структура

- `src/main/kotlin/docfiller/template/` — сканирование и заполнение `.docx` (Apache POI)
- `src/main/kotlin/docfiller/excel/` — чтение/запись `people.xlsx`
- `src/main/kotlin/docfiller/ui/` — интерфейс (Compose Desktop)
- `tools/convert_sz_template.py` — разовый конвертер, которым образец с цветовой
  разметкой был превращён в шаблон с плейсхолдерами

Тесты: `gradlew.bat test`.
